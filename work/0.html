RA8875 DRM Driver

Migrating RAiOs RA8875 display controller from fbdev to DRM in Linux

One of the ongoing effort in the DRM subsystem of the Linux kernel is to migrate all drivers from the old fbtft system to the more modern DRM framework.

Working DRM driver tested with Raspberry Pi 3B

Currently in the review phase, with the first RFC sent on April 2026, and working on the v1 patch sometime in May.
